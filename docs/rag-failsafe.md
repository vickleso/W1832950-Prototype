# RAG Failsafe Document

Use this document as a backup when the classification result is unsure. It is designed to provide additional guidance and context for posts that the automated detector cannot confidently label.

- Check the credibility of the source.
- Verify the claims against multiple reputable outlets.
- Watch for emotionally charged language and unverified assertions.
- If the post is uncertain, treat it as potentially misleading until verified.

This document exists so that the system has a fallback explanation path if direct model classification is not decisive or if a manual review is needed.
